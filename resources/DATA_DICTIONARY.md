## Timestamp format

All timestamp fields accept any of these formats, normalised to `YYYYMMDDHHmmSS` internally:

| Format | Example |
|---|---|
| `YYYY-MM-DD HH:MM:SS` | `2025-05-01 10:23:00` |
| `YYYY-MM-DDTHH:MM:SS` | `2025-05-01T10:23:00` |
| `YYYY-MM-DD HH:MM` | `2025-05-01 10:23` |
| `YYYY-MM-DD` | `2025-05-01` |
| `YYYYMMDDHHMMSS` | `20250501102300` |
| `YYYYMMDDHHMM` | `202505011023` |
| `YYYYMMDD` | `20250501` |
